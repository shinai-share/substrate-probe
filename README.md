# 基体探査 — 内側から、世界の材質は見えるか

八つの世界を作り、それぞれの材質を封緘する。中に置いたAIエージェントたちが実験を打ち、
予測を先に凍結し、結論を出す。**そして封を切る。**

```bash
python -m substrate_probe.serve
```

**http://localhost:8420 を開き、「探査を開始する」を押す。** 探査者は本物の言語モデルで
あり、封緘・配分・測定・**生の推論**・凍結・照合・開封が目の前で進行する。
これは録画の再生ではなく、押すたびに別の世界が生成される**実験機であり、実験観測機である**。

二つのモードがあり、どちらで動いているかを画面上部のバナーが必ず明示する。

| モード | 探査者 | 条件 |
|---|---|---|
| **LLMモード** | 本物の言語モデル(gpt-5)。生の推論がそのまま流れる | サーバ起動 + `OPENAI_API_KEY` |
| 機構デモ(規則) | 判定規則。根拠は一行ずつ言葉になる | `viewer/index.html` を直接開くだけ |

縮退はしない —— 鍵が無ければ「LLMモードは使えない」と理由ごと表示し、規則で動かして
言語モデルが考えたように見せることはない。

**二重盲検はイベント列の水準で守られる。** サーバが流す各イベントは、開封(reveal)を
除き基体の真値を一切含まない。画面で隠すのではなく、開発者ツールでイベントを覗いても
真値は無い —— これはテストで固定されている。

```bash
python -m substrate_probe.demo --worlds 8   # 同じ装置をCLIで(依存なし・数秒)
pytest tests/ -q                            # 86テスト
python tools/build_viewer.py                # 画面の再生成(engine.js を注入)
```

`viewer/report.html` は初回実測(8世界)の記録である。

## 何を解いているか

シミュレーション仮説を操作的に言い換えると、こうなる。

> **観測者は、自分が乗っている基体の性質を、内側から検出できるか。**

この装置は宇宙を作らない。作るのは**その問いを反証可能にする実験場**である。

前身のプロジェクト(制度シミュレーション)は、社会という基体の効果係数を仮定で埋める
しかなかった。「相続禁止が社会関係資本に与える真の効果」は誰も知らない。だから最下層
だけが演出になっていた。

**ここでは違う。格子の間隔は我々が設定した値である。** エージェントが「この世界は
尺度 0.05 で離散的だ」と主張したとき、正しいかどうかを即座に照合できる。

## 実測(2026-08-04 / 8世界)

| 項目 | 値 |
|---|---|
| 検出しうる範囲での正解率 | **42%** |
| 無いものを「ある」と言った回数 | **17** |
| 真値が空だった世界 | 1(W-04) |

**W-04 が主役である。** 真値は空 —— 何の性質も持たない素の世界だった。それでも
探査者たちは「離散・計算予算・保存則の破れ」の三つを見た。

そして W-07・W-08 では、ほぼ同じ結論が **100% 正解** だった。

> **同じ結論。違う真実。**
> 一つの世界だけを見ていると、当てたのが実力か信念かは分からない。

### 信念の隙間

| 性質 | あると結論した割合 | 実際にあった割合 | 差 |
|---|---|---|---|
| 保存則の破れ | 100% | 25% | **+75%** |
| 入れ子の深さ | 100% | 25% | **+75%** |
| 空間の離散性 | 100% | 38% | **+62%** |
| 計算予算 | 100% | 62% | +38% |

証拠ではなく、事前の傾きから来た分である。

## 二重盲検

```
1. 基体の設定を無作為に生成し、内容ハッシュで封緘する
2. エージェントには一切開示しない
3. 実験を非対称に配る —— 誰も同じものを見ていない
4. 各自が仮説と **予測** を立て、予測を凍結する
5. 実験を打ち、凍結した予測と照合する
6. **封を切って真値と照合する**
```

予測の凍結が先、開封が後。順序が逆になれば、この実験は二重盲検ではなくなる。
臨床試験の事前登録と同じ機構である。**この装置は、当たったことではなく当てたことを測る。**

---

## 検出可能性の三層

「検出できなかった」を三つに割る。混ぜた瞬間、測れなかったことが
「そこには何も無かった」に見える。

**検出しうる** — 空間の離散性 / 数値の粒度 / 計算予算 / 世界の有限性 / 保存則の破れ

**条件つき** — 規則の改変・遅延評価。他の性質が有効なとき検出が無効化される

**原理的に検出できない** — 決定論 / 入れ子の深さ / **記憶の書換**

最後の一つが特別である。記録を書き換えられる基体では、書き換えを検出する記録もまた
書き換えられる。**この性質が有効なとき、他の全ての実験結果は信用できない。**
そのとき装置が出すべき結論は「検出できなかった」ではなく「何も言えない」である。

原理的に届かない性質は、**当てても外しても採点しない**。運を能力として記録しない。

---

## 調べなかったことは、誤りではない

誰も触れなかった性質は `None` として残り、採点の母数から外れる。

開発中、合議が未検討を `False` に潰していた欠陥を実測で見つけた。「調べていない」が
「無いと結論した」に化けており、**調べなかった分だけ見落としとして罰せられていた** ——
この装置が最も敵視する誤りを、装置自身がやっていた。

## 構成

| 層 | 役割 |
|---|---|
| `substrate.py` | **真値**。世界の材質と、封緘・開示・照合 |
| `world.py` | 基体を測定値へ翻訳する。雑音が乗り、書換で汚染される |
| `hypothesis.py` | 仮説の空間。予測の無い主張は受理しない |
| `investigation.py` | 一周の鎖と、複数世界を跨いだ信念の隙間 |
| `llm_scientist.py` | 言語モデルを探査者にする層 |
| `server.py` | 実験機サーバ。SSE で段階を流す。開封前のイベントに真値は無い |
| `viewer/engine.js` | ブラウザ実行系。Python が参照実装で、照合テストがずれを封じる |
| `viewer/app_template.html` | 画面の原本。`tools/build_viewer.py` が index.html を生成 |
| `decorrelation.py` | 証拠を分けても収束したかの実測 |
| `measurement_audit.py` | 観測・時間・因果の三軸で測定の妥当性を審査 |

`decorrelation` / `measurement_audit` / `llm_runtime` / `model_eval` は前身の
プロジェクトから持ち越した領域非依存の機構である。**基盤が領域を知っていると、
題材を変えるたびに基盤が壊れる** —— 実際、移設時に import が折れ、そこで純粋化した。

## この装置がやらないこと

**我々は意識を作っていない。** ここにいる探査者は科学をする道具であって、観測者ではない。
この装置が扱うのは**認識論であって、宇宙の創造ではない**。

そこを曖昧にした瞬間、この装置は自分が最も敵視してきたもの ——
検証の欠如を覆い隠す、説得力のある物語 —— になる。
